# 用語点検スキル（yougo-tenken）

書き上げた原稿を渡すと、**読者が詰まる専門用語**を洗い出すAIエージェント用スキルです。
**Claude Code と Codex CLI の両方で、同じファイルが動きます。**

## なぜ作ったか

「専門用語は噛み砕いて書く」は、たいてい指示として持っています。それでも残ります。

- 書いている本人には、その語が**難しく見えない**
- `GAS（Google Apps Script）` のように、**略語を伸ばしただけで説明した気になる**
- 3回目では説明していても、**初出で詰まった読者は戻ってこない**

このスキルは、**書く側ではなく、書き終えたあとの点検**に効きます。

実際、作者が公開済みの記事にかけたところ、**タイトルに入っている「KPI」が本文で一度も説明されていない**ことが見つかりました。

## できること

原稿を渡すと、こう返ってきます。

```
| 用語 | 初出のあたり | 判定 | いまの書き方 | 言い換え候補 |
```

判定は4段階です。

| 記号 | 意味 |
|---|---|
| ✅ | 説明済み。初出で、何をするものかが分かる |
| ⚠️ | **展開しただけ**（略語を伸ばした／カタカナにしただけ） |
| ❌ | 未説明 |
| — | 説明不要。読者にとって一般語 |

表のあとに、**まず直す3件**だけが挙がります。

## やらないこと

- **本文を書き直しません。** 指摘と言い換え候補を出すだけです
- **「5歳児にも分かるように」しません。** 読者は自分の分野では専門家で、こちらの分野を知らないだけです。幼稚な言い換えは、相手を見下した文章になります
- **すべての用語を指摘しません。** 全部並べると、どこから直すか分からなくなります
- 文体や誤字は見ません。用語だけです

## インストール

```bash
git clone https://github.com/mamagotolab/yougo-tenken-skill.git ~/skills/yougo-tenken

# Claude Code
mkdir -p ~/.claude/skills
ln -sfn ~/skills/yougo-tenken ~/.claude/skills/yougo-tenken

# Codex CLI（公式に案内されている置き場所）
mkdir -p ~/.agents/skills
ln -sfn ~/skills/yougo-tenken ~/.agents/skills/yougo-tenken
```

実体は1つ。symlinkで両方から使えます。依存パッケージはありません。

## 使い方

```
articles/draft.md の用語点検をお願いします。読者は業務改善を任された非エンジニアです。
```

**読者を伝えてください。** 誰向けかによって、説明が要る語は変わります。
伝えなければ、スキルが1問だけ聞きます。

## 自分の現場に合わせて、直して使ってください

中身は全部Markdownです。プログラムを書ける必要はありません。

| ファイル | 何を決めているか | 直したくなる場面 |
|---|---|---|
| `SKILL.md` | 判定の基準、出力の形、指摘を3件に絞るルール | 指摘が多すぎる／少なすぎる |
| `reference/iikae.md` | 言い換えの実例集と、よく出る用語の言い換え方向 | **自分の業界の用語が入っていない** |

とくに `reference/iikae.md` は**足していく前提**です。自分の分野で「これは説明が要る」と思った語を書き加えてください。
